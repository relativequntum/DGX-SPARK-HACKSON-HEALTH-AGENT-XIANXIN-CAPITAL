# 项目路线图

## M0：仓库与安全基线

- 协作宪法、Issue/PR 模板、CODEOWNERS、CI；
- 产品边界、安全与隐私说明；
- 阶段间会话、消息、安全和情感事件契约；
- DGX Spark 本地模型兼容性 spike。

## M1：阶段一动态文字预问诊

- 同意流程和患者端文字交互；
- 动态问题树与状态机；
- 红旗规则、安全拒答和降级路径；
- 患者摘要与医生结构化摘要；
- 匿名演示病例、安全金集和断网演示。

负责人：史静宇 `@relativequntum`。

## M2：阶段二多模态动态预问诊

- 本地 ASR/TTS 方案实测；
- 转写确认、语音输出和文字无障碍回退；
- 动态头像状态机与音频驱动；
- 与阶段一统一会话和安全事件。

负责人：陈科顺 `@keshunchen`。

## M3：阶段三情感识别

- 独立授权和隐私策略；
- 语音情感与面部表情模型实测；
- 统一的置信度、时间窗和 `unknown` 语义；
- 偏差、噪声、遮挡、多人等失败测试；
- 只辅助沟通，不改变医疗风险判断。

负责人：曹昶皓 `@ari1206`、李虹雨 `@hongyu`。

## M4：集成演示

- GPU 资源预算、模型预热和降级；
- 全链路离线演示脚本；
- 急症、提示词注入、隐私泄漏和幻觉红队；
- 领域专家签字与已知限制；
- 冻结演示版本、模型校验值和演示录像。
