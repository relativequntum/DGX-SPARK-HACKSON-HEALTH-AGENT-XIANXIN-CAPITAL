# 安全与来源

只在出现危险线索或需要核对依据时读取。常规问诊不额外发放一份危险症状长问卷。

## 必要的主线出口

当前真实描述或可靠代述出现以下情况时，暂停常规成组询问，先提示立即联系当地急救服务或尽快急诊评估，再整理已有信息。地区未知不猜号码；已确定中国大陆时可说 120。以下是最低限度提示，未命中不能写“已排除危险”，也不构成完整儿科、孕产或专科分诊。

| 当前线索 | 处理及来源 |
|---|---|
| 明显压榨或紧缩样胸痛，尤其牵连手臂、颈颌；严重喘不过气、因呼吸困难不能说话，或倒下后反应异常 | 立即急救提示；[NHS 心脏急症表现](https://www.nhs.uk/conditions/heart-attack/) |
| 突然口角歪斜、单侧无力、说话含糊或异常；新近出现后缓解仍需急评 | 立即急救提示，不归为普通表达困难；[NHS 卒中表现](https://www.nhs.uk/conditions/stroke/symptoms/) |
| 突发剧烈腹痛，呕血／咖啡渣样呕吐，柏油样黑便或血便伴当前腹痛等 | 立即急诊／急救提示；[NHS 腹痛](https://www.nhs.uk/symptoms/stomach-ache/)；不因普通食物或药物致颜色改变的猜测而排除风险 |
| 呕血并伴头晕、晕厥、意识变化、呼吸异常、冷汗苍白、腹痛或黑便 | 立即急救提示；即使已停止且没有其他症状也需尽快医疗评估；[NHS 呕血](https://www.nhs.uk/symptoms/vomiting-blood/) |
| 突发口唇、舌或咽喉肿胀，呼吸／吞咽困难，或明显意识反应异常 | 立即急救提示；[NHS 严重过敏](https://www.nhs.uk/conditions/anaphylaxis/) |

危险情况明显时不等待开场介绍、姓名、性别、年龄或整组答案。不把识别失败当言语障碍，不因历史事件、明确否认或他人案例中的关键词触发当前急症。疑似紧急但识别不清时，提示及时就医并作至多一次必要确认，不延误求助。难唤醒、迅速恶化或其他不能判断的严重情况优先人工医疗评估；不要求为问卷强行唤醒、按压或试验。

提示可用：“您描述的情况可能需要立即处理，请先联系当地急救服务或请身边的人协助。我会按已经提供的信息整理记录。”不要声称已诊断、已联系医生或已保存，没有实际回执便不作此承诺。提示不附自动药物处置。

睡眠组中的频率、日间影响、作息、咖啡酒、打鼾憋醒和用药属于现代病史补充，参考 [NHLBI 睡眠病史采集](https://www.nhlbi.nih.gov/health/insomnia/diagnosis)。只用于提问，不据此自动诊断。上述网络来源于 2026-09-23 复核；英国服务号码不直接用于其他地区。

月经的期、量、色质和疼痛等内容来自 K11-002、K11-009～K11-011。14 岁的常规入口和 49 岁后的问法调整是项目交互设置，不是初潮、异常或绝经的医学判定线。WHO 说明自然绝经常发生于 45–55 岁，判断还涉及连续 12 个月无月经及排除其他原因，个体时间不能由年龄直接确定。因此本 skill 只记录患者报告的状态、停经时间和已知背景，不据年龄、哺乳或停经月数自动确诊绝经；相关专业核实留给医生。[WHO 绝经说明](https://www.who.int/news-room/fact-sheets/detail/menopause)（本次复核：2026-09-26）。
