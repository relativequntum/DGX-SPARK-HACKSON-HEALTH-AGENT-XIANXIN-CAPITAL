# 成组关联问法

本文件是候选要点和组装规则，不是必答题库。话术均为项目改编；教材出处和旧问题对应关系见[来源索引](来源索引.json)。主诉阶段只读相关段落；常规阶段按顺序读取 G-MENSTRUAL（适用时）和 G-ROUTINE。

## 组装规则

1. 先区分主要症状、顺带伴随症状、已知疾病和就诊目的。疾病名称不能替代当前症状；一个症状不能自动推成另一个症状或病因。
2. 从“具体表现、时间与变化、程度与影响、加重缓解、直接相关伴随表现、已有诊治”选择缺失且有用的要点。同一方面尽量合并成一句，通常 3–6 项；若大部分已知，只问余下少数项或直接前进。
3. 关联表现是供患者确认的候选，不是已存在的事实。选择最相关的少数表现，不为找证型而列出一整串组合。疼痛感觉、位置变化、牵涉方向可以并存，分别记录。
4. 主诉和患者明确希望重点处理的新诉求才展开完整组。顺带说睡不好、便稀等先收录，可同时覆盖相应常规项，不把每个阳性答案变成新问卷。
5. 一组回答不全也向前推进。只有当前症状是谁的、是否属于本次发作等关键歧义可短澄清；其余留缺项。月经常规组回答后进入四项常规，四项常规组回答后直接进记录；普通异常均不自动触发细问。

患者主动改变最想解决的问题时，更新重点并只调整尚未进行的关联询问；保留已经取得的其他信息，不从基本信息重启。患者明确要求补充某个新症状时可处理该诉求，不能借此自动重开所有已涉及主题。

## G-GASTRIC｜胃痛、上腹痛

适用：患者明确说痛；仅胃胀或胃炎不套用疼痛组。“胃痛”原话不能直接当作胃病诊断。

开场：“关于这次胃痛，请一起说说下面几项；已经提到的我会记下，不用重复，知道多少说多少。”

| 候选要点 | 简短问法及文字选项 |
|---|---|
| 位置 | 最明显疼在哪里？上腹正中／上腹左侧／上腹右侧／其他或多处／说不清；以患者描述为准 |
| 病程 | 大概多久了，是一直疼还是一阵阵，第一次还是反复出现？可报近几天、几周、几个月或自述，不强求日期 |
| 感觉和影响 | 像胀痛／隐隐痛／烧灼痛／针扎痛／绞着痛，还是其他？感觉可多选；对吃饭、睡觉或活动的影响另外记录 |
| 加重缓解 | 空腹、吃饭后、受凉、保暖或情绪变化时有没有明显变化？只记录已经经历的情况，分清加重和缓解，不让患者自行按压或试验 |
| 伴随表现 | 是否同时胃胀、反酸烧心、嗳气、恶心呕吐等？可多选、明确都没有或自述。呕血、柏油样黑便等主动报告优先走安全出口 |
| 已有诊治 | 为这次或同类不适看过医生、做过检查、用过药吗？只补已知结果与效果，可选未处理／记不清／自述 |

若已说“上腹正中胀痛三天，空腹更明显”，删除位置、这次病程、已知感觉和空腹关系的重复问法；不因某属性还能细分就重新问整项。相关药名不记得便记未详，不强迫找报告。

“痛得睡不好”覆盖睡觉；“吃不下”覆盖吃饭；仅“饭后更痛”不覆盖吃饭。病程、痛感、既有保暖反应等来源见 K05-001、K05-002、K05-020；诊治经过见 K02-005。

## G-SLEEP｜睡眠不好

适用：睡眠为主诉，或患者明确提出希望重点补充。仅伴随提及时收录并覆盖睡觉，不自动展开本组。

| 候选要点 | 简短问法及文字选项 |
|---|---|
| 具体表现 | 难睡着／容易醒且难再睡／早醒／梦多或不解乏／白天特别困／其他，可多选 |
| 时间频率 | 持续多久，大致偶尔、经常还是几乎每天？允许估计或不记得 |
| 实际睡眠和影响 | 一晚实际大约睡多久，白天精神、注意力或活动受影响吗？允许只回答其中一部分 |
| 相关打扰 | 有没有同时心慌、烦躁、夜间出汗、胃部不适、夜尿，或打鼾憋醒？按已有线索选少数候选，不要求每项展开 |
| 作息与背景 | 最近熬夜、倒班、压力，或茶、咖啡、酒等情况有变化吗？只记录时间关系，不断定病因 |
| 已有处理 | 是否就诊、用药或尝试过其他办法，效果怎样？允许未处理／记不清／自述 |

睡不好不自动写为失眠诊断，梦多也不等于失眠。不追问梦的详细内容。后续先按主线检查月经板块（适用时）；四项常规组只问尚未涉及的吃饭、大便、小便，若已说夜尿，小便也不重复问。

睡眠表现及相关兼症来自 K08-001～K08-005；作息、日间影响、咖啡酒、打鼾憋醒等包含现代病史采集补充，依据见[安全与来源](安全与来源.md)，不冒称教材原话。

## G-DISEASE｜只报疾病名称或检查异常

适用：如“我有慢性萎缩性胃炎”，但未说明当前不适。未提到症状 ≠ 明确无症状。先问以下一组，基本信息缺项可以合并：

1. **最近有没有不舒服？** 结合所述疾病给少数通俗例子；胃部疾病可选胃痛、胃胀、反酸烧心、恶心、胃口不好、其他。可多选并指出最困扰的一项；另提供“目前没有明显不适／不清楚／暂不回答”，与阳性选项互斥。
2. **这次主要希望医生帮助什么？** 改善不适／了解检查结果／复诊或调理／其他。
3. **大概什么时候、通过什么方式得知的？** 医生告知／报告结论／其他或记不清；有实际材料可提供，纯语音可口述，不以报告上传为继续条件。

有明确症状才进入相应症状组，删去本组已问内容。明确无明显不适时记录实际就诊原因，不编成胃痛主诉；疾病只写“患者自述……”及已知来源。若已经回答“没有其他补充”，直接进入常规板块，先检查月经适用性与覆盖，再检查四项；否则按主线提供一次补充机会。不清楚或拒答保留原状态，不能反复追问直到得到阳性答案。

“目前没有明显不适”不自动代表月经或吃饭、睡觉、大便、小便均正常，仍按适用性分别检查覆盖。依据 K02-002、K02-005、K02-006。

## G-GENERAL｜其他主诉的关联候选

在通用的病程、变化、影响和已有诊治之外，仅按主诉选下面相关的一行。以下不是专科全覆盖，表外主诉用通用组，不猜测知识库没有展开的专业细节。

| 当前重点 | 可以成组询问的区别与关联 | 教材知识索引 |
|---|---|---|
| 其他部位疼痛 | 明确部位、痛感、是否移动或牵连、时间变化、活动及已有冷热反应、直接伴随不适 | K05-001、K05-002、K05-016 |
| 胃胀、腹胀 | 位置、胀还是痛、进食关系、食欲或实际食量、嗳气反酸、恶心及排便变化 | K06-008、K06-009 |
| 头晕 | 昏沉还是旋转、时间及诱因、站立或活动影响、头痛耳鸣、恶心或乏力 | K06-002、K07-009 |
| 心慌、胸闷 | 具体感受、起止、诱因、胸痛、气短或乏力；当前危险表现先退出主线 | K06-003、K06-004 |
| 怕冷、发热感 | 时段、冷与热是否同现或交替、已经保暖后的变化、已有实测体温、汗与相关不适 | K03-001～K03-005、K03-026 |
| 出汗异常 | 清醒还是睡中、醒后是否变化、部位和量、环境活动背景、同时不适 | K04-001、K04-004、K04-005 |
| 口干、口渴或吃饭变化 | 分别了解口干感与实际饮水、想不想吃与实际吃了多少；选相关的胃部或二便变化 | K09-001、K09-002、K09-005、K09-008～K09-010 |
| 口中异常味道 | 味道原话、时间、与进食关系，依线索选反酸、口干或胃部不适；不让患者选证型 | K09-021～K09-028 |
| 大便变化 | 次数与平时比较、干稀成形、排出感觉、颜色或可见血、腹痛腹胀；选与当前问题相关的部分 | K10-002～K10-004、K10-010、K10-013 |
| 小便变化 | 次数、每次或总体量、颜色、排出感觉、饮水或夜间情况；尿频不等于尿量多 | K10-016～K10-020、K10-023、K10-026 |
| 乏力、身重、麻木、瘙痒 | 先分清实际感受，再问部位、发生变化、活动影响与直接伴随表现；乏力不写成身重 | K06-011～K06-015 |
| 耳或眼不适 | 单侧双侧、突然或渐变、听力或视觉具体变化、相伴不适；不将模糊、复视与旋转混同 | K07-002～K07-005、K07-007～K07-012 |
| 月经、带下为主要诉求 | 围绕本次诉求选择实际周期或日期、经量与平时比较、色质、疼痛时段；带下问变化与周期、妊娠等已知背景。月经的常规覆盖另见 G-MENSTRUAL，已有信息不重问 | K11-002、K11-009～K11-013 |
| 难以自述者由看护者回答 | 同样围绕主诉成组，但改问实际观察的进食、睡眠、排泄、活动变化与起病；保留患者能表达的原话 | K12-001、K12-003、K12-005 |

不要求为问卷量体温、按压腹部或实施查体；已有测量可记录值、时间和来源。未测不等于正常。生理带下背景不能直接写成疾病。女性月经常规板块不等于自动展开带下、孕产或完整妇科病史；是否适用也不以成年或婚姻状态为界。

## G-MENSTRUAL｜女性月经常规板块

**独立放在主诉及补充询问之后、常规四项之前。** 不与吃饭、睡觉、大小便混成同一问题组，也不以主诉与月经相关为触发前提。先读取已知信息；已提到近期月经情况、当前不来月经的背景、自述绝经，或已明确不清楚、拒答、待核实，均无需再常规追问。仅有遥远的痛经史不代表近期月经情况已知。

### 适用与分流

- 沿用本项目的年龄提示：已知女性且 14 岁及以上时检查此板块。14 岁以下若已说明来月经或有相关诉求，同样按实际情况记录和询问；不能把 14 岁作为初潮的生理界限，也不向幼儿机械发放月经问题。
- 14–49 岁且状态未明时，可直接用下方简短概况组，并允许说明从未来过、最近未再来或自述已绝经。超过 49 岁且状态未明时，优先用状态问法；超过 51 岁也不能自动写已绝经。
- 患者已明确说当前仍来月经，也按已涉及处理，不为补齐概况再问；年龄不能覆盖这条事实。已知妊娠、哺乳期等相关停经背景，或自述已绝经时，收录现有信息，不强问当前周期、经量。哺乳本身不等于无月经，近期没来也不等于绝经。
- 性别、年龄或生理适用性不足以判断时，不猜测，也不为触发本板块反复索要已拒答的基本信息；记录适用性待核实后前进。明确不适用则跳过。患者主动提供月经信息时按事实收录，不受账号性别标签限制。

### 一组成组问法

**月经概况：**“再单独了解一下月经情况：最近来得规律吗，每次大约几天？经量与平时相比怎么样，有没有明显痛经，或者经血颜色、血块的变化？如果目前不来月经，也可以直接说明。不清楚或暂时不想回答的内容可以跳过。”

文字界面用同一组的简短选项；以下为候选，允许少答，不要求每项齐全：

| 要点 | 表达与选项 |
|---|---|
| 来潮时间与天数 | 来得规律／比平时早／比平时晚／早晚不定／其他；持续天数可自述或不记得。周期指两次开始之间的间隔，行经天数指每次出血持续多久，分别保留 |
| 经量、色质变化 | 经量与平时差不多／增多／减少／其他；颜色或血块变化可另行多选或自述，不把一个答案拆成多个已确认事实 |
| 经期疼痛 | 有／没有／不清楚；可一并说对日常生活有无影响，不因回答有就自动启动痛经细问 |

以上各项均允许“暂不回答”或自述。若患者说明目前不来月经，停止要求填写来潮细项，保留其原话和已提供的原因或时间；不把这些空白写成正常。末次月经日期、疼痛时段等在月经为主诉或当前诉求确有需要时纳入关联组，不作为常规答全条件；经量不要求估造毫升数。

**状态尚不明确的较年长患者：**“再单独了解一下，您现在还有月经吗？如果还有，可以一起说说最近是否规律、经量和痛经情况；如果已经绝经，大概多久了？”文字状态可选“仍有月经／自述已绝经／最近没来，是否绝经不清楚／其他／暂不回答”。相关细项仅向对应分支展示，允许自然语言回答。只回答状态也算本轮已经处理，随后前进，不再为填齐概况多问一轮。

视频同步展示本组，口头概括“来潮情况、经量、痛经或变化”；纯语音先说“最近月经来得规律吗？经量和痛经有没有明显变化？”患者可连续描述，不读整张表。两种方式均不要求屏幕操作。

**本组回应后直接检查四项缺项。** 月经回答中顺带说的睡眠、吃饭或二便情况同时收录并去重；漏答、不清楚、拒答或普通异常均不重复发本组。四项已涉及则直接展示记录。明确停止或危险线索仍优先走出口。例：已有“月经不规律，睡不好、大便稀”，跳过月经板块，只合问吃饭和小便；月经组只答“经量比以前多”也前进，不强补周期、色质和痛经。

教材采集内容见 K11-002、K11-009～K11-011。独立板块、年龄提示、概况组及向前推进规则为项目设计；绝经状态的记录边界见[安全与来源](安全与来源.md)。

## G-ROUTINE｜常规四项合问

**四项始终检查覆盖，只向患者问尚未涉及的方面。** 覆盖依据是本次或近期情况；遥远病史不能代替当前情况。不清楚、拒答和待核实均已有处理，不反复追问，也不当作正常。

| 方面 | 足以不再重复问的例子 | 仍不足以认定已涉及的例子 |
|---|---|---|
| 吃饭 | 胃口好／吃得少／吃不下／饭量和平时一样；家长观察到奶量减少 | 仅饭后胃痛、喜欢热饮、口苦；不能由饭后痛推断食欲 |
| 睡觉 | 睡不好／睡得好／夜里易醒／疼痛影响睡眠／日间特别困 | 仅夜间胃痛而未说睡眠受影响 |
| 大便 | 稀溏／干结／次数多／排便正常／有黑便等 | 仅腹痛或不想谈其他症状 |
| 小便 | 尿频／夜尿／量少／小便正常／照护者观察尿布变化 | 仅喝水少、口渴，不能推小便正常或量少 |

“吃饭睡觉和大小便都和平时一样”明确涵盖四项；“大小便正常”涵盖大便与小便。“其他都正常”只有明确回应当前列出的几个方面时才按那个范围记录；脱离指向的“都挺好”保留原话，不扩成四项正常。

全部缺失时，一次呈现下面四行；已有的行删除：

| 方面 | 患者问法与选项 |
|---|---|
| 吃饭 | 最近胃口和吃饭量怎么样？与平时差不多／不太想吃或吃得少／吃得多或容易饿／其他 |
| 睡觉 | 最近睡得怎么样？睡得可以／难睡着／容易醒或早醒／梦多或不解乏／白天特别困／其他 |
| 大便 | 最近大便怎么样？和平时差不多／偏干或费劲／偏稀或次数多／其他 |
| 小便 | 最近小便怎么样？和平时差不多／次数多或夜里多／量少／疼痛或不畅／其他 |

每行均允许“不清楚／暂不回答”；睡眠等可并存异常采用多选，“与平时差不多”等整体答案与阳性选项互斥。复合选项按原样记录，选择“不太想吃或吃得少”不能被拆成食欲和食量均下降；“和平时差不多”不能自动改写为医学上的正常。看护者的吃饭问法改为“实际吃下或喝奶的量与平时比怎样”。

例如已有“睡不好，大便稀”：只问“还想了解两项：①最近胃口和吃饭量怎样？②小便怎样？”不要再展示完整四行让患者重新确认。语音可说：“睡觉和大便的情况已经记下了。再一起说说最近吃饭和小便怎么样。”

**收到这一组回答就整理记录。** 若答“吃得少，小便正常”，记下后展示记录和两个选择，不接着问饭量、尿次。若只答吃饭，小便写“已问未答”，同样展示记录。患者之后选择“还有补充”才继续。
