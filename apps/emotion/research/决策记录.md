5. **两条纪律**：合作医院的任何数据、病历、来访者信息一律不碰，博士贡献的是流程知识不是数据；自杀风险红旗走确定性规则，命中即中止对话并转人工，规则由博士亲自定。
6. **博士分工**：知识包主编——量表选型、问诊分支、红旗规则、20 个合成病例、盲评预诊单。不写工程。
7. **选线尺子**：核心 = 开源密度、论文密度、做得出来；辅 = 知识包成熟度、合规与伦理、本地性叙事、差异化；赛后可持续权重低。

## 2026-09-14 追加（情绪采集线调研边界）

11. **预诊单「望/闻」写法：B 为主、C 托底、A 不做。** B = 按精神状况检查（MSE）条目写可观察信号（外观、行为、言语、情感、目光）；C = 自评量表分数；A = 情绪标签（悲伤 72% 这类）明确不做。
12. **通道**：面部（只上 AU、目光、头姿；不做人脸识别、不做表情分类）+ 语音特征（语速、停顿、音量、基频）+ 言语内容（ASR 转写 → 本地 LLM 按 MSE 条目归纳 + 词汇标记）+ 身体只做「坐姿 / 坐立不安」一条。对话通道（问诊分支、量表施测）与生理信号不进本轮调研。
13. **市场范围**：中国心理测评 / AI 心理产品；国际临床级语音 / 多模态生物标记公司；开源工具、模型与公开数据集；其他行业情感计算只看可迁移技术。
14. **证据分档**：T1 = 监管许可（NMPA / FDA / UKCA）或独立临床验证；T2 = 同行评审论文；T3 = 只有官网宣称。只有 T1 / T2 算「做到了」，T3 只列名。
15. **许可**：比赛阶段不卡许可，报告逐条标注商用风险。硬约束四条：ARM64 + CUDA 13 能跑、中文支持、完全离线、体积能与主 LLM 共存。
16. **交付**：Markdown 进 `调研/人的情绪采集/` + 同步发一个网页版链接给团队。
17. **方向仍未定**：三线都要按同一把尺子调研，情绪线先跑；共用引擎（Spark 部署与模型、Skills 规范与 harness、前两届项目）并入本轮，后面两线不再重查。

## 2026-09-14 18:05 追加（观察通道的采集时机）

20. **观察在对话与答题过程中同步进行**，不设单独的「观察环节」。对话（问诊分支 + 量表施测）是刺激源，面部 / 语音 / 言语 / 坐姿四个通道在整个会话中持续运行。参照：DAIC-WOZ / SimSensei 的虚拟访谈者采集方式；区别在于我们只记 MSE 观察条目，不记情绪标签。
21. **观察对齐到问题**：每条观察带「当时在答哪一题」的时间戳，预诊单写成「回答『睡眠』时停顿增多、目光移开」这类与问题绑定的描述，而非全程平均值。技术含义：观察进程与问诊状态机共用一个时钟（ch2 harness 章要给出落地方式）。
22. **个体基线**：会话开头的基本信息问答作为该来访者的「基线段」，后续变化相对于本人基线比较，不与数据集平均值比较。这是小学线「个体基线偏移」引擎在单次访谈内的缩小版。
23. **知情可见**：来访者必须知道摄像头与麦克风开着、系统记录什么，屏幕上有可见提示，可随时要求「只做问卷、不做观察」。写进 skill-card 边界与路演话术。
