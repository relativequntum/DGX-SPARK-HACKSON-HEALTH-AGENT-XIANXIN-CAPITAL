## 核实口径（与 `docs/safety-and-privacy.md` 一致）

- 证据分档：T1 = 监管许可或独立临床验证；T2 = 同行评审论文；T3 = 仅官网宣称，只列名不算「做到了」。
- 硬约束四条：ARM64 + CUDA 13 能跑、中文支持、完全离线、体积能与主 LLM 共存。
- 面部只上 AU / 目光 / 头姿，不做人脸识别与表情分类；输出按精神状况检查（MSE）可观察条目写，附置信度、时间窗、模型版本与 `unknown`，不出情绪标签。
- 摄像头、麦克风、情感分析独立授权，屏幕常驻可见提示；原始音视频只在内存短时处理，不落盘。
